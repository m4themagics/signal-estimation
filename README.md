# Оценка параметров модулированных сигналов на фоне шума

Исследование обратной задачи: по зашумлённой записи АМ-сигнала восстановить
параметры модуляции. Метод максимального правдоподобия против спектрального
оценивания; граница Крамера—Рао как теоретический предел; пороговый эффект
и вырождение идентифицируемости — воспроизведены и объяснены экспериментально
(метод Монте-Карло).

## Основные результаты

*(подробности, вывод формул и код — в [research/parameter_estimation.ipynb](research/parameter_estimation.ipynb))*

1. **МП-оценка асимптотически эффективна**: выше порога эмпирические СКО оценок
   всех параметров совпадают с границей Крамера—Рао.
2. **Пороговый эффект имеет двухслойную природу и «этажность»**: сначала отказывает
   инициализация (захват ложного пика периодограммы), и только глубже — сама информация
   в данных; параметры модулятора разваливаются на ~10 дБ раньше несущей, потому что
   боковые полосы слабее. Диагностика — сравнение спектрального и оракульного стартов:
   при N = 512 порог по f_модулятора ≈ 0 дБ, по f_несущей ≈ −10 дБ, оракульный старт
   держится на CRB во всём исследованном диапазоне (до −20 дБ).
3. **Скорости сходимости подтверждены**: СКО оценки частоты убывает как N^(−3/2)
   (измерено −1.51), амплитудных параметров — как N^(−1/2) (измерено −0.52),
   в согласии с классикой (Rife & Boorstyn, 1974).
4. **Идентифицируемость теряется при m → 0** со скоростью m^(−1) по СКО — вырождение
   информационной матрицы Фишера, присущее задаче, а не методу.

## Структура

```
├── research/   исследование (Jupyter, содержательная часть)
│   └── parameter_estimation.ipynb   МП vs спектральная оценка, CRB,
│                                    Монте-Карло, порог, идентифицируемость
├── core/       C++17: наивное ДПФ + БПФ Кули—Тьюки, самопроверка и бенчмарк
└── demo/       интерактивная иллюстрация постановки (АМ/ЧМ/кольцевая, Web Audio)
```

## Воспроизведение

```sh
python3 -m venv .venv
.venv/bin/pip install -r research/requirements.txt
# открыть ноутбук в VS Code / Jupyter с ядром из .venv; полный прогон — ~1 мин
cd core && make run    # C++: тесты БПФ + бенчмарк
```

Демо — просто открыть `demo/modulation.html` в браузере.
